# Afrikas dyr – Sigrids dyrequiz

Interaktiv norsk læringsapp for barn med 16 afrikanske dyr, dyreplakat, norsk tale og en morsom bildequiz.

## Funksjoner

- **Dyreplakat:** Trykk på et dyr for å høre det norske navnet. Dyret får en kort glødeeffekt under avspilling.
- **Quiz:** Velg riktig dyr blant to bilder etter å ha hørt spørsmålet og dyrenavnet.
- **Tilbakemelding:** Grafisk markering og norsk tale ved riktig eller feil svar.
- **Ett forsøk per oppgave:** Gå videre til neste spørsmål etter svaret.
- **Uten internett:** Bilder og lyd er innebygd i `index.html`.

## Bruk

Åpne `index.html` i en moderne nettleser på mobil, nettbrett eller datamaskin. Ingen installasjon er nødvendig.

## Publisering

Kan publiseres som en statisk nettside via GitHub Pages med `index.html` i rotmappen.
